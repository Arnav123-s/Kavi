# Correcting the interacting state configuration

Author: [Arnav123-s](https://github.com/Arnav123-s)

7 September 2026. Recorded before the direct event-learning course.

## Architectural correction

The preceding experiments learned static predicate decisions and executed their proposed arithmetic in a stateful runtime. That is insufficient to demonstrate learning of the state transitions themselves. This experiment replaces the language predicate tree with an acquired recurrent event graph. Each word event changes its current state. Its learned final output selects an existing arithmetic configuration and argument direction.

The interpreter couples three activities: held input quantities, the changing interpretation state, and the final calculation. An event triggers each update once. The output remains unavailable until the explicit end event and completion boundary. Only current state and quantities are retained during execution; there is no list of earlier word events. The caller still supplies the text, and the learned graph and vocabulary occupy persistent storage.

The states are discrete digital states. There are no continuous pendulum equations, learned physical forces or quantum amplitudes. The test addresses the missing learned-transition mechanism within the pendulum analogy, not every proposed interaction. The update rule and coupling schedule remain supplied.

## Source teaching

Use original ASDiv questions from the existing admitted-source training partition. Restrict this first direct-state course to exactly two explicit quantities and at most 60 tokens. The source formula supplies one of six oriented arithmetic relations. No numerical examples, sentence variants or worked answers are generated.

Sort eligible questions by normalized-signature SHA-256 and take the first 144, in increments of 48. The vocabulary is the 128 most frequent alphabetic word stems in those training questions; count ties by spelling. This uses all selected training inputs before incremental labels. Other alphabetic words enter the shared `other` port. Numerical values enter held quantity slots; the event graph sees first-quantity and second-quantity markers. These supplied abstractions are not claims of learned lexical meaning. A contradictory encoded lesson must be reported, never silently removed.

If the shared `other` port collapses different required outputs in a teaching increment, record the collision and repeat that increment's fits with all literal word stems from the teaching inputs as distinct ports. This fallback changes the supplied encoding, is selected only by a training contradiction, and must retain earlier correct answers. It does not invent an intent category or acquire a semantic synonym relation.

Development uses the first 80 eligible questions in the earlier ASDiv development partition, or all if fewer exist. Freeze before revisiting eligible questions in its original final partition. This is another follow-up on a known project bank. The new learner itself receives no final labels during fitting or selection.

## Learning and correction

Start with source event sequences and their required final operation ports. Build a temporary prefix graph, then fold compatible states and close their transitions under deterministic consistency. This is the same class of state-merging procedure used by the earlier finite-state learner, implemented with sparse edges for the larger language alphabet. The target transition graph is not supplied.

At each increment, score the new source questions before exposing their labels. Their published corrections join the earlier teaching constraints; reconstruct a successor and require every earlier correct teaching answer to remain correct. No teacher mistake is treated as a truth label. The resulting graph can change its states, recurrent edges and output connections. The deployed artifact retains those structures and the vocabulary, not the teaching sequence list.

For each increment, fit seeds 7 and 19. Select highest development accuracy, then highest current teaching accuracy, then smallest artifact, subject to finite retention. Include keeping the previous configuration after the first stage. Counts on a saved prefix graph form a memorization control after final freezing; it retains literal event paths and supplies no inferred loops. Record prefix versus folded size and test behavior. Graph structure can itself encode memorized examples, so absence of a separate example table does not prove absence of memorization.

## Scope and controls

Use the visible window with Pause, Resume and Stop, a five-minute wall limit and observed 512 MiB worker ceiling. Limit each fit to 10,000 temporary states, 10,000 merge proposals and 100 million counted work units. Failed candidates and exhausted budgets remain recorded; continue only if the overall run budget permits. Count sparse copies, closure work, inference events, all selection work and runtime costs.

The old arithmetic registry is reused without retraining. A correct selected relation must execute through that registry after the final event. This is direct learned language-to-state-to-operation coupling, not a general natural-language or research-level system. It still cannot represent multi-operation scope, unrestricted variable binding or jointly learned coupling schedules. Those limitations remain separate from this experiment's results.
