## Reading rule

The documents separate four categories: implemented behavior, measured evidence,
research proposals, and open questions. A design explanation is not a result;
a successful unit test is not a claim of broad intelligence; and a cited source
is not permission to ingest its full content. The current implementation
boundary is authoritative when it conflicts with an aspirational blueprint.
