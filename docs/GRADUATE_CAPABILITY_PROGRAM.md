# Graduate capability program

Author: [Arnav123-s](https://github.com/Arnav123-s)

## Objective and present position

The project objective covers three tracks: applied mathematics and scientific computing; physics and mathematical modelling; and language, literature and philosophy. Kavi has not demonstrated master's-level competence in any of them. The current evidence concerns narrow executable arithmetic and annotated sentence patterns. Completing a curriculum, reading a text, adding a component, or obtaining a compact model is not a qualification result.

Graduate study requires more than isolated numerical answers. Cambridge's [Part III mathematics program](https://www.maths.cam.ac.uk/postgrad/part-iii/node/53) uses written examinations and an essay. MIT's [graduate Quantum Theory II syllabus](https://ocw.mit.edu/courses/8-322-quantum-theory-ii-spring-2003/pages/syllabus/) provides a physics scope reference. Cambridge's [MPhil in English Studies](https://www.english.cam.ac.uk/admissions/graduate/mphil.html) includes specialist study and an individual dissertation. These sources guide the kinds of competence to assess; they do not endorse Kavi, define an automatic model score, or constitute teaching already performed.

## Development sequence

| Stage | Mathematics and computing | Physics and modelling | Language, literature and philosophy |
| --- | --- | --- | --- |
| Foundations | Correct integers, fractions, signs, composition and error handling | Quantities, units, simple state transitions and model assumptions | Sentence roles, reference, negation, explicit claims and evidence |
| Structured reasoning | Variables, exact algebra, vectors, matrices, calculus and proof steps | Conservation, mechanics, differential equations and uncertainty | Compositional meaning, paragraph relations, argument validity and source-grounded interpretation |
| Undergraduate integration | Derivations and numerical methods on unfamiliar problems | Selecting and deriving models, numerical error and experimental comparison | Comparing interpretations, objections, original-language context and sustained argument |
| Graduate assessment | Advanced unseen problems, justified derivations and a reproducible computational project | Advanced modelling, quantum/statistical methods, approximation analysis and independent investigation | Close reading, scholarly synthesis, defensible criticism and an independently evaluated research essay |

The representation must support a stage before bulk teaching starts. Gaps are assigned a reproduction, a repair, and new verification cases. A repair may add an engineered execution mechanism, improve a teaching procedure, or change a learned configuration; the record must say which. Existing successful behavior is retested after each change. Failed final tests become development evidence for subsequent versions, never invisible additional training for the same reported assessment.

## Assessment contract

For every claimed capability, specify inputs, permitted tools, output requirements, resource limits, reference answers or grading rubric, and the exact model version. Keep acquisition examples, correction examples, development checks and final assessments distinct. Once final cases guide a repair, that version needs new final cases to establish transfer.

Numeric and symbolic assessments require checking the solution as well as the final value where a derivation is requested. Physics work requires explicit assumptions, units and approximation error. Literary and philosophical work requires evidence, coherent argument, consideration of alternatives and accurate treatment of sources. Parsing a phrase about an argument is not evaluating its validity.

Before a graduate-level claim, assemble a subject-specific assessment with independent specialist review, sufficient breadth, multiple task families, and a separately reviewed project or essay. Specify pass criteria before running it. Do not convert a chosen engineering success threshold into an academic degree equivalence. Report separate results by track and scope rather than one intelligence level or a percentage of a master's degree.

## Teaching sources

Use original works and scholarly or institutional editions across languages, regions and periods. Record author, work, edition, source location, original language, translation where applicable, and permitted use. Project Gutenberg is excluded from new teaching. Source text stays separate from executable knowledge: lexical storage, a source-linked claim, a learned formal representation and an independently justified conclusion are different objects.

Current foundation trials use authored examples. They do not claim to have taught a corpus of scientists, philosophers or literature. Later source-based teaching must test meaning and transfer, not merely count processed pages or recognized words. Final assessments should include works or problem families not used to design the teaching material.

## Mechanism experiments

| Direction | Controlled question | Acceptance evidence |
| --- | --- | --- |
| Relevant reuse | Does retaining useful components help later acquisition? | Matched search budgets, unrelated/fixed controls, held-out tasks and full library costs |
| Correction | Does feedback improve a reusable rule? | Fresh answers improve and earlier valid answers survive |
| Search interference | Does a larger library obstruct useful paths? | Repeat the failed workload, test an explicit repair, and assess on new inputs |
| Representation expansion | Can signs, fractions, vectors or complex states be handled correctly? | Independent arithmetic/model checks, resource enforcement and learned compositions above the new representation |
| Thermal or catalytic rules | Does the proposed dynamics help relative to simpler control? | Same information and compute budgets; accuracy, retention and actual work |
| Equation components | Can an equation or solver be acquired or reused appropriately? | Unseen states, justified domain assumptions and numerical error measurements |
| Learned restructuring | Can the learner replace computations while preserving valid behavior? | Checked dependencies, new costs and independent retained-skill evidence |
| Learned internal semantics | Do representations transfer without supplied concept labels? | Tasks and behavior beyond the annotation schema, with supplied structure clearly identified |
| Learned update rules | Can experience improve how later learning occurs? | Independent task sequences and separately held-out evaluations of the update procedure |

These are research questions, not promised outcomes. Mechanisms from the earlier external review remain deferred unless separately adopted. The current direct-composition search condition is an explicit local experiment responding to measured loop-search overhead; it does not implement the review's proposed probabilistic search, e-graphs or abstraction algorithms.
