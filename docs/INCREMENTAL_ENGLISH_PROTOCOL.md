# Incremental teaching through current input activity

Author: [Arnav123-s](https://github.com/Arnav123-s)

7 September 2026. Recorded before the incremental course. This course connects acquired English predicate routes to a current-state input processor and the signal execution substrate. It remains an elementary mathematical-language experiment. Research-level work across subjects is a target, not the starting capability.

## Input processing

Consume words in order. Retain the latest five-token window, numerical slots, bounded local context around those slots, and active feature bits used by the acquired predicate graph. The state does not retain the full sentence or a history of every token. The application still supplies the input text and the tokenizer still reads it; that input storage is counted separately from the state object.

Each word updates the current predicate activity. Later words can change the active operation choices. At input completion, the learned preferences select a variable-input computation. Execute that computation through the signal runtime and release the answer after settlement. The feature definitions, event schedule and arithmetic substrate are supplied. Acquired predicate branches control the proposed interpretation. This is not a learned continuous oscillator or a general intent learner.

Before teaching, compare the active features against the original batch feature definitions on ASDiv training and development questions. Compare only predicates actually present in the acquired model. This is a representation regression, not a new accuracy measurement. Keep the original configuration unchanged if the representation disagrees.

## Genuine source lessons

Start from the first acquired English configuration and its 389 ASDiv teaching questions. Preserve the original source exclusions and signature partitions. Add human-written GSM8K base questions whose published worked program uses every explicit quantity once, with at most five quantities. Exclude normalized signatures present in any ASDiv final question. Do not use generated solutions or question variants.

Order eligible GSM8K rows by the SHA-256 of their normalized input signature. The first incremental batch contains eligible one-operation questions. The next two batches contain up to 80 distinct two-operation questions each. These are additions within the elementary-language foundation, not promotions to an advanced subject level.

Use the original ASDiv development partition and the first 80 eligible three-quantity GSM8K development rows for selection. Keep training and development signatures disjoint. Original official test scores and the ASDiv test bank are follow-up evidence after freezing, not new independent examinations.

For each batch, reconstruct candidate predicate graphs at depths 12, 24 and 48 with minimum leaf size one. Teaching pairs come only from the published formula annotations. The deeper candidates test whether the earlier leaf constraint prevented useful correction. They do not establish a new learning algorithm; the Gini split rule remains supplied.

An admissible candidate must retain every correct answer that the previous configuration produced on the earlier teaching bank. Score those obligations against the published answers, not the previous model's incorrect outputs. Include keeping the current configuration as an admissible option. Among admissible candidates, select highest development accuracy, then highest current teaching accuracy, then smallest serialized configuration.

This check protects finite known behavior. It cannot guarantee unseen retention. Record rejected candidates, regressions, teaching errors and any change in later follow-up accuracy. Do not change the protocol or claim a new final result after seeing follow-up answers.

Record predictions on each new teaching batch before its first correction. Those records identify actual teaching failures; they are not an independent examination. A later questioning experiment may use teaching feedback under its own declared protocol. This course does not yet learn a decision to ask.

## Curriculum advancement

A move beyond the elementary-language foundation requires at least 90% on its declared development bank, no losses on the earlier teaching obligations, and a subsequently reserved independent evaluation. The present course may teach additional foundation examples while that threshold is unmet. It must not label exposure to harder material as mastery.

Original college-level worked examples have been acquired from the SciBench author repository for later mathematics, physics, chemistry and statistics stages. Their source snapshot is e14e0ca3d3db0f02928a18d435b9c3d15656a7c5. Generated model responses are excluded. The separate Classical Dynamics, Physical Chemistry and Differential Equations question files remain reserved and unparsed during this foundation course. No college-level teaching or testing result is claimed here.

The source is Wang and coauthors' [SciBench paper](https://arxiv.org/abs/2307.10635) and [author repository](https://github.com/mandyyyyii/scibench). The paper describes human extraction and checking of original textbook questions and reference solutions. The repository license does not remove the original textbook authors' attribution or rights. Source bodies remain local.

## Controls and reporting

Use one visible worker with Pause, Resume and Stop, a five-minute limit and the existing 512 MiB observed worker-memory ceiling. Each candidate has a 60-million-unit teaching allowance; each question has a one-million-unit work allowance. Work exhaustion counts as failure on that question. Overall time or memory exhaustion stops the course and preserves its partial record.

Record all candidate work, inference work, representation checks, dependency checks, display pacing, model sizes, wall time, CPU time and available worker-memory measurements. The live display shows arriving words, provisional routing and the final calculation. It must distinguish a displayed inference trace from a persistent teaching update.

After the last completed batch, freeze the selected configuration. Revisit the 150-question ASDiv bank and count exactly which earlier correct answers were lost or gained. A candidate with later losses is not an automatic replacement for a deployed model. Scientific source storage and unrun later stages remain separately identified.
