# Machine-oriented computation

Author: [Arnav123-s](https://github.com/Arnav123-s)

Kavi's architecture should exploit the strengths of ordinary computers: exact execution, explicit storage, reusable programs and independent verification. Biological similarity is optional and must be justified by measured benefits.

A typed program library can express discrete operations precisely. A learned numerical model can interpret uncertain signals or rank candidate computations. Their interface must preserve types, provenance, failure states and resource costs.

External retrieval, tool execution, planning and proof checking are distinct capabilities. A tool result is not evidence that the learner has acquired the tool's algorithm. A checked proof concerns the encoded statement under its formal assumptions.

Begin with exactly verifiable procedures. Expand into uncertain language interpretation only after the core demonstrates useful transfer and retention. The detailed architecture and hypothesis backlog are in the [specification](KAVI_ENGINEERING_SPECIFICATION.md).
