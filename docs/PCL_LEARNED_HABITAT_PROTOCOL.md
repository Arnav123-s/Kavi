# Learning a role-based template boundary

Author: [Arnav123-s](https://github.com/Arnav123-s)

Protocol fixed before this source run, 8 September 2026.

## Design question

Can the template itself be inferred and revised from confirmed teaching, rather than supplied as a list of semantic categories? Treat the two cognitive layers as a learned habitat defining admitted roles/arrangements and a learned circuit operating inside it. A separate fixed device/search envelope still limits memory, component cycles, candidate work and execution.

This first habitat is an input-role grammar. It does not contain people, buildings, spatial reality, persistent situations or discovered physical laws. Those are future world-model requirements. Do not describe this boundary grammar as a complete internal world.

## Inference rule and replacement contract

For each event symbol, collect every observed one-hole context (prefix,suffix) in the confirmed finite language. Symbols with equal context sets share an unnamed role. A pattern records the role sequence of an admitted input. Neither truth-value roles nor connective roles are named in advance. Rebuild the entire role partition and pattern collection when confirmed new observations require it.

The resulting role products represent the observed finite language exactly. Equality of one-hole contexts makes substitutions within a role preserve membership. Repeated substitutions therefore introduce no unobserved word. This is structural factorization, not demonstrated extrapolation to new input patterns.

For another teaching round, expand the old template transiently and query the old circuit for its answers. This derives retention obligations from the deployed configuration, not retained lesson records. Explicit contradictory new targets correct those inputs; other supported outcomes must be preserved. Infer the successor habitat and reconstruct the complete inner circuit. Commit both together only when every new target, protected target and prior admitted input passes. Interruption or rejection leaves the old world unchanged.

Retention expansion is capped at 4,096 words, with input lengths at most 64. This first algorithm is finite; it does not solve retention for an unbounded world. Unsupported events or arrangements return no answer at the learned boundary.
